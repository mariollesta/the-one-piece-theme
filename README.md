---

## Installation

1. Open **Extensions** in VS Code (`Ctrl+Shift+X`)
2. Search for **The One Piece Theme**
3. Click **Install**
4. Open the Command Palette (`Ctrl+Shift+P`) → **Preferences: Color Theme** → select **The One Piece Theme Dark**
